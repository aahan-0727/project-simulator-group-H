# Project Features

The Student Portal currently includes the following student features and data fields:

- Student ID & Name
- Academic Information:
  - Department
  - Semester
  - Credit Hours
  - CGPA
  - Academic Status
- Contact & Personal Information:
  - Email Address
  - Phone Number
  - Address
  - Age
  - Gender
- Documentation:
  - Organized Changelog (`CHANGELOG.md`)
  - Team Information (`README.md`)
